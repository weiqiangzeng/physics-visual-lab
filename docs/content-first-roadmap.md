# 内容优先建设路线

更新日期：2026-08-01

## 当前判断

Physics Visual Lab 已有 65 个原创实验、统一状态协议、移动端布局、模型边界、实验指南和三步探究任务。下一阶段的主要矛盾不是继续扩充目录，而是让用户更容易找到实验、读懂证据、识别误区并解决使用问题。

## 公开产品方法借鉴

本项目只提炼公开方法，不复制课程原文、付费材料、视觉素材或源码。

| 产品 | 公开方法 | 本站转化 |
| --- | --- | --- |
| PhET | 先探索，再用目标和少量问题聚焦因果；帮助中心区分通用技术问题与具体模拟提示 | 实验内保留低文字负担；知识库同时支持通用问题和实验上下文 |
| The Physics Classroom | 互动实验连接教程、活动单、概念检查和故障排查 | 每个实验逐步补齐“现象—证据—解释—迁移”，并提供可复现的问题反馈格式 |
| GeoGebra | 帮助中心以搜索为首入口，资源可按主题组织和复用 | 中文自然语言检索、问题分类、深链接和实验回跳 |
| Gizmos | 模拟配套词汇、目标、建议顺序和讨论问题 | 将高频核心实验整理为原创、可复现的课堂方案与学生记录单 |

## 内容质量门槛

每个实验后续提质时必须同时回答七个问题：

1. 用户进入后 10 秒内是否知道要观察什么？
2. 是否要求先预测，而不是直接公布结论？
3. 动画、实时读数、图像和公式是否描述同一状态？
4. 用户能否指出哪条证据支持结论？
5. 是否明确至少一个高频误区及其反例？
6. 是否说明模型近似、边界和不能外推的区域？
7. 是否有一个改变条件后的迁移问题？

## 实施顺序

### 第一层：先解决“不会用”

- 建立 30 条使用知识库，覆盖快速上手、操作、现象解读、故障和隐私。
- 从首页和所有实验页进入，携带当前实验上下文。
- 使用自然语言同义词检索，支持问题深链接。

### 第二层：再解决“看到了但没读懂”

优先补强双缝干涉、折射与全反射、抛体运动、圆周临界、机械能、电场、电磁感应、共振、理想气体和带电粒子。每项增加可直接看到的：

- 当前现象的一句话解释；
- 图表和读数的证据对应；
- 高频错误判断及反例；
- 一个边界或迁移问题。

### 第三层：形成可持续内容循环

- 知识库未命中词作为新内容候选，但当前版本只在本地统计，不上传用户查询。
- GitHub Issue 使用统一复现模板收集真实问题。
- 每次内容更新同时校验物理正确性、桌面/移动端、文字溢出和旧状态恢复。

## 内容优先后的第二阶段

- 先完成使用知识库，再从 65 项免费实验中精选 10 项建立教师资源中心。
- 每项提供五段式课堂流程、三个参数预设、学生记录单、教师打印版和场景分享。
- 使用事件只保存在本机；真实问题通过用户主动提交的 GitHub Issue 收集。

## 仍不建设

- 会员、支付、学生账号、云端进度和第三方统计；
- 在没有真实使用证据前继续扩展实验数量；
- 复制其他网站的课程原文、付费材料、视觉素材或源码。
