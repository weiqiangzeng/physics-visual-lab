# 八维质量升级框架

更新日期：2026-08-28

## 目标

Physics Visual Lab 已具备 65 个原创实验。接下来不再以增加目录数量或堆叠功能为目标，而是把已有模型逐步提升为教师可直接演示、学生可独立探究的课堂工具：**一个主问题、一套可信状态、少量高价值操作、可核对的证据**。

参考同类产品时，只记录可观察的产品结构和交互规律，例如“主装置承担主要操作、精确输入承担微调、读数和图表从同一状态派生”。不提取或复用受保护的课程文案、视觉素材、数据集或实现代码。

## 审计单位

一次审计以一个物理模型为单位，而不是以某个页面是否好看为单位。每个模型都要有一张简短的质量卡：

- 目标概念、前置知识和要破除的误区；
- 解析关系、单位、符号约定、近似条件和失效边界；
- 主画布中真正可直接操控的对象，以及精调入口；
- 一个主观察量和对应的图像或数据证据；
- 课堂的 3 分钟演示、10 分钟探究和课后迁移入口；
- 桌面、手机、边界状态和交互回归证据。

## 八维门槛

### 1. 科学性

- 公式、单位、方向、守恒关系和数量级来自同一解析状态；动画不能替代计算结果。
- 明示适用条件、零值和临界情况；屏幕比例仅表示关系时必须说明，不能伪装成真实比例。
- 每次改动至少复核一个标准参考点、一个反向或极限边界，并把结果写入回归。

### 2. 教学性

- 首屏只服务一个课程目标，先让学习者预测，再显示证据和解释。
- 用一项参数变化对应一个可观察因果，避免把互不相关的变量同时开放。
- 每个核心模型至少设置一个高频误区及可操作的反例，并给出改变条件后的迁移问题。

### 3. 可视性

- 主装置、关键状态和结论证据有明确层级；装饰不与物理对象竞争注意力。
- 颜色、箭头、轨迹、坐标和图线全页语义一致，导出量必须能追溯到主画布中的同一对象。
- 视觉表达不能制造错误直觉，例如把示意粒子速度当作真实尺度、把非线性关系画成正比。

### 4. 交互性

- 最值得调节的物理对象优先在主画布直接拖动；数字框或滑杆只用于精确复现和微调。
- 空白拖动不改变状态，按下真实对象不跳变，拖动、键盘和预设始终得到同一可解释结果。
- 操作后立即更新装置、读数、图像和提示；对手机提供等价且易触达的路径。

### 5. 认知性

- 一个视图只保留当前判断所需的信息；派生设置、深层公式和高级叠加层默认收起。
- 参数名、读数名和图表问题避免重复表达；单位、方向和状态只在必要位置出现。
- 不以“信息很多”制造专业感，优先缩短从操作到证据的路径。

### 6. 技术性

- 物理模型、渲染和交互分层；可复用原语通过明确状态和公共 API 接入。
- 关键公式有脚本参考值和边界测试；关键手势有真实浏览器桌面/手机回归。
- 无资源失败、控制台错误、空画布、横向溢出和重置残留；新增依赖必须有明确收益。

### 7. 场景性

- 默认状态适合教师在投影上 3 分钟讲清现象；常用预设适合 10 分钟学生探究。
- 主画布在普通笔记本和手机上均先可见，课堂不依赖鼠标悬停或隐藏手势。
- 任务、打印材料和知识库只补足课堂流程，不与实验主界面争夺空间。

### 8. 有效性

- 每个结论须能指向一条可见证据，并能通过反例或边界状态检验，不用结论性文案代替理解。
- 当前阶段只能把“已完成设计和交互证据”记为内部有效性；“提升理解”须等待真实课堂或用户反馈验证。
- 收集到的反馈要能回到具体模型、参数、操作和现象，成为下一轮修改依据。

## 执行闭环

1. **抽样参考与本地诊断**：记录可迁移的结构规律，给本地模型标出八维缺口；不复制外部表达。
2. **选题排序**：优先处理高频、概念门槛高、已有用户反馈且能通过共享原语带动多页的缺口。
3. **单一目标改造**：一轮只处理一个相互关联的问题，例如“关键对象改为直接拖动并同步证据”，不做无关重绘。
4. **双层验证**：先跑公式/边界/状态测试，再跑真实浏览器桌面和手机手势、截图和布局检查。
5. **效果记录**：更新质量卡、已知边界和下一优先级；涉及学习效果的结论只在取得真实反馈后升级。

## 近期队列

- 第一批：已经有较多使用反馈、且最适合检验“主画布直接操作 + 同步证据”模式的力的合成与分解、折射与全反射、双缝干涉、光电效应、电阻率测量。
- 第二批：将同一原则迁移到电场与电路、运动与能量、振动与波、电磁感应及带电粒子等高频课堂模型。
- 第三批：根据课堂和使用反馈处理剩余模型的误区、可访问性、性能和跨页一致性，不为凑数新增重复实验。

## 本轮参考结论

对当前会员实验的结构性抽样显示，力的合成、折射/全反射、双缝和光电效应虽属于不同内容，但都将主装置、关键参数、实时读数和一至两种针对性证据保持在同一状态链路中。本站后续借鉴这一组织原则，同时保留原创模型、文案和视觉实现；每个模型根据概念选择证据，不复制统一的页面外观。
