# 理想气体：从活塞运动到宏观状态量

## 核心教学问题

活塞改变体积时，为什么粒子空间分布和器壁碰撞的视觉特征会变化，而压强又能用宏观状态方程准确描述？本实验把微观图像与 `p、V、T、n` 状态量放在同一条证据链上。

## 状态模型

宏观状态使用理想气体状态方程：

```text
pV = nRT
```

温度还对应分子平均平动动能：

```text
⟨Eₖ⟩ = 3kT / 2
```

压强、体积、温度、物质的量和图表当前点均由同一个解析状态派生。

## 宏观量与微观样本

画布中的粒子是少量代表性统计样本，用于观察空间分布、运动方向、碰壁和活塞变化。宏观压强由 `pV=nRT` 计算，不由屏幕粒子数量直接测得；粒子尺寸、速度和碰撞亮点按教学可见性放大，也不代表真实尺度和真实时间。

## 核心演示路径

默认场景为“微观压强”：保持 `n`、`T` 不变，命中活塞后向内拖动改变体积。容器变窄、粒子区域变密，压强读数和 `p–V` 图当前点同步变化；操作后提示继续对照 `pV=nRT`。

空白区域点击不改变体积，只有命中活塞附近的可视命中区才会开始拖动；拖动保留按下位置偏移，避免活塞跳变，桌面和触摸使用同一 Pointer Events 路径。

## 三条过程路径

- **等温压缩**：`T` 不变，`V` 减小，`p` 增大，`pV` 保持不变。
- **等容加热**：`V` 不变，`T` 增大，`p` 增大，`p/T` 保持不变。
- **等压膨胀**：`p` 不变，`T` 增大，`V` 增大，`V/T` 保持不变。

## 气体种类对照

在相同 `n、V、T` 下，不同理想气体的压强相同；分子质量影响速率统计。氦气的方均根速率高于氧气，但不因此改变状态方程给出的压强。

## 当前模型近似与局限

- 分子间作用、分子自身大小和真实碰撞时间尺度被忽略；过程状态使用解析理想气体模型。
- 屏幕粒子不是完整分子动力学模拟，不能将少量粒子的瞬时碰撞数当成实测压强。
- 尚未获得真实课堂反馈。

## 20～30 秒 Recordly 片段

0～4 秒：展示活塞、粒子、初始 `p、V、T` 和 `pV=nRT`。

4～12 秒：拖动活塞向内压缩，观察容器体积变小、粒子区域变窄、压强上升和 `p–V` 图当前点移动。

12～18 秒：切换等温或等压场景，指出当前保持不变的量和图表中的过程约束。

18～25 秒：停留在状态读数与结论区，说明粒子动画提供微观解释，宏观压强由状态方程计算。
