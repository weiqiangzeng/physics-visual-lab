# 光电效应：频率改变能量，光强改变数量

## 核心教学问题

为什么提高光强不能让低频光释放电子，而提高频率可以？本实验把单个光子的能量、电子逸出、最大初动能、遏止电压和宏观光电流放在同一条可操作证据链上。

## 频率与光强的不同作用

- 频率决定单个光子能量：`Eγ = hν`。当 `hν < W₀` 时没有光电子；当 `hν > W₀` 时，`Eₖ,max = hν − W₀`。
- 光强在本模型中表示单位时间到达阴极的代表性光子数，主要改变电子事件数量和光电流，不改变单个光子能量、`Eₖ,max`、`U꜀` 或截止频率。
- 页面用波长滑块控制频率，并明确提示“波长越短，频率越高”，避免把波长和频率误认为同向变化。

## 能量账本与截止条件

实时读数显示 `ν`、`ν₀`、`hν`、`W₀`、`Eₖ,max`、`U꜀`、最大速率和光电流。结论区区分：

- `ν < ν₀`：无光电子，光电流为零；
- `ν ≈ ν₀`：临界发射，最大初动能和遏止电压接近零；
- `ν > ν₀`：产生光电子，能量账本满足 `hν = W₀ + Eₖ,max`；
- 反向电压达到 `U꜀`：最快光电子也不能到达阳极，光电流归零。

## 当前模型假设

- 阴极材料使用固定逸出功；光子能量使用 `hc/λ`；最大初动能使用爱因斯坦光电方程；遏止电压使用 `eU꜀ = Eₖ,max`。
- 光电流使用收集效率的教学近似，粒子数量和事件率也按屏幕可见性缩放。它用于比较参数关系，不代表真实实验的绝对电流精度。
- 当前阶段不加入电子能量分布、释放延迟、空气阻力或其他复杂误差模型。

## 推荐参数与演示路径

1. **低于截止**：钠、`λ = 550 nm`、中等光强、`U = 0 V`。读数显示 `ν < ν₀`、无光电子、光电流为零。
2. **跨过临界**：把波长从 550 nm 向 540 nm 拖动。短波长意味着更高频率；电子从无到有，`Eₖ,max` 和 `U꜀` 从接近零开始出现。
3. **提高频率**：继续拖到约 500 nm，观察 `hν`、`Eₖ,max` 和 `U꜀` 一起增加。
4. **提高光强**：保持频率不变，提高光强。光电流和代表性电子事件率增加，但 `Eₖ,max`、`U꜀` 不变。
5. **反向电压**：将极板电压调到 `−U꜀` 附近，光电流归零，验证遏止电压由最大初动能决定，而不是由光强决定。

## 20～30 秒 Recordly 片段

0～4 秒：展示钠材料、`ν`、`ν₀`、`hν` 和 `W₀`，此时低于截止频率，没有电子。

4～10 秒：拖动波长从 550 nm 到 540 nm，再到约 500 nm，展示跨过截止条件后电子出现，`Eₖ,max` 和 `U꜀` 增加。

10～16 秒：保持频率不变，提高光强，展示光电流和电子事件率增加，而能量账本不变。

16～24 秒：施加反向电压直到 `U꜀`，展示光电流归零，并强调“频率改能量，光强改数量”。
