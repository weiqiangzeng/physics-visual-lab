# 旗舰实验质量门槛

旗舰实验不是统一皮肤，而是统一证据链。每页必须让学生完成“预测 -> 操作 -> 观察 ->
解释 -> 验证”，且装置、读数、图像和结论来自同一物理状态。

## 七维评分

每维 0–3 分。任一维低于 2 分即不通过；七维平均分不得低于 2.5。

1. **物理正确性**：数值模型、单位、方向、参考系、守恒账本和至少一个独立参考点一致；
   3 分要求同时有边界参考点或反例。
2. **状态一致性**：场景切换、控件、画面、读数、图像、标签和重置共享单一状态；
   桌面与移动场景导航必须一一对应。
3. **直接操控**：核心物理量可在主装置上拖动或点选，且与精确输入互相同步；不能只有滑杆。
4. **联动证据**：主装置、实时读数和至少两个分析视图同步更新；视觉缩放不参与数值计算。
5. **模型边界**：临界、失效或近似条件在触发时可见；指南说明未建模因素，不把示意动画冒充实测。
6. **学习闭环**：至少三步探究路径、当前问题、公式/结论读数、实验指南和可保存任务记录齐全。
7. **产品质量**：首屏可操作、重置可复现、键盘/标签可辨认、桌面和手机无溢出，Canvas 非空且无控制台或资源错误。

## 自动门槛

运行：

```bash
node scripts/audit-flagship-quality.mjs
```

脚本检查结构、桌面/移动场景一致性、直接操控入口、分析视图、共享协议、公开测试接口、
重复 ID 和基础可访问性。它是必要条件，不替代物理参考点和浏览器视觉验收。

在 Playwright 已安装或由 `NODE_PATH` 提供时，运行双端浏览器回归：

```bash
node scripts/verify-flagships-browser.cjs http://127.0.0.1:4192
```

设置 `QA_SCREENSHOT_DIR` 可同时输出六张全页截图。

## 浏览器验收

- 桌面使用 1280x720，手机使用 390x844；两端逐场景切换并扰动至少两个参数。
- 每页核对清单中的全部参考点，并检查一次重置、一次直接拖动和一次边界状态。
- Canvas 以非背景像素检查确认非空；同时检查资源失败、控制台异常、横向溢出和标签重叠。
- 初始状态必须在 3 秒内表达实验对象、可操作位置和当前物理结论；纯静态空场景不通过。

## 实现约束

- 物理计算与绘制分离；高风险模型优先放入独立 `*-model.js`，并暴露确定性函数供参考点测试。
- 页面状态必须有一个权威来源。场景跳变可以改变默认参数，但不得让标签、滑杆和内部值分叉。
- 新实验复用工作台布局和平台协议，原创实现文案、图形和数值模型，不复制参考站课程内容或素材。
